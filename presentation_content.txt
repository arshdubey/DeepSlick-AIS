Slide 2: IDEA TITLE & PROPOSED SOLUTION
--------------------------------------------------
Idea Title: DeepSlick-AIS: Orbital Surveillance & Forensic Attribution Engine

Proposed Solution: 
An autonomous platform that detects marine oil spills via satellite and forensically traces them back to the responsible ships using ocean drift modeling and historical maritime tracking.

Detailed Explanation:
1. Detection: Ingests Synthetic Aperture Radar (SAR) imagery to automatically detect and segment oil slicks regardless of cloud cover or darkness.
2. Hindcasting: Utilizes a Lagrangian Drift Engine (Runge-Kutta 4th order integrator) with MetOcean data (wind and sea currents) to trace the oil's path backward in time to its exact origin.
3. Attribution: Cross-references the temporal origin point with historical Automatic Identification System (AIS) logs to flag the exact suspect vessel that caused the spill.

How it addresses the problem:
Currently, illegal bilge dumping goes unpunished because oceans are vast and the evidence disperses before authorities arrive. DeepSlick-AIS bridges this gap by mathematically reversing ocean currents to connect the environmental crime directly to the polluter.

Innovation and uniqueness:
Most existing systems stop at "detection". DeepSlick-AIS introduces "attribution" by fusing SAR, hydrodynamics, and AIS tracking into a single, automated forensic pipeline.

Slide 3: TECHNICAL APPROACH
--------------------------------------------------
Technologies to be used:
- Frontend: Next.js, React, Tailwind CSS
- 3D Visualization: Deck.gl, Three.js, React-Map-GL
- Backend: FastAPI, Python
- Analytics/Math: NumPy, SciPy, Shapely (for Runge-Kutta drift engine)
- Data Sources: Copernicus Sentinel-1 (SAR), NOAA/Copernicus Marine Service (MetOcean), AIS Data Streams

Methodology and process for implementation:
1. Data Ingestion: System receives automated SAR satellite imagery alerts.
2. Analytics: FastAPI backend runs the Drift Engine to compute the slick's past 36-hour trajectory (Hindcast) and future 36-hour trajectory (Forecast).
3. Correlation: A spatio-temporal query checks the slick's origin against the AIS vessel database.
4. Visualization: The Deck.gl tactical dashboard renders the slick polygons, drift particles, and suspect vessel routes in a high-performance 3D environment for Coast Guard operators.

Slide 4: FEASIBILITY AND VIABILITY
--------------------------------------------------
Analysis of the feasibility:
Highly feasible. Free, open-access satellite data (Sentinel-1) and MetOcean data (Copernicus) already exist. The drift algorithms and web visualization technologies are proven and currently implemented in our working prototype.

Potential challenges and risks:
- High sea states and waves can create false positives in SAR imagery.
- Processing heavy hydrodynamic models in real-time requires significant compute power.
- Spoofed or missing AIS transponder signals from rogue vessels.

Strategies for overcoming these challenges:
- Implement AI/ML false-positive filtering using optical satellite cross-verification.
- Optimize the Runge-Kutta engine using vectorized numpy operations or GPU acceleration.
- Flag "dark vessels" (ships that turned off their AIS) by noting gaps in the transmission logs near the spill origin.
